# 4 DoF Robotic Arm Control and Kinematics

Project developed for the **Robotics course (34753)** at DTU in the 2026 fall semester.

This repository covers the complete analytical design and closed-loop control of a 4-axis serial robot powered by Dynamixel smart servos, featuring an integrated end-effector camera. The study combines comprehensive theoretical derivations—spanning spatial kinematics, motion profiling, singularity assessment, and rigid-body dynamics—with practical validation on real hardware and virtual simulation platforms.

## Topics

* Direct and inverse kinematic analysis
* Motion trajectory generation
* Singularity tracking and static load evaluation
* Manipulator dynamics
* Vision-guided robotic operations
